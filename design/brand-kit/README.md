# AURYA — Brand Kit v1

Assets para colocar no repositório e fornecer ao Claude Code.

## Conteúdo
- `reference/AURYA_DESIGN_REFERENCE.png`: arte de referência aprovada (moodboard, não telas exportadas).
- `logos/logo-primary.svg`: reconstrução vetorial aproximada do logo com fundo azul.
- `logos/logo-transparent.svg`: reconstrução vetorial aproximada transparente.
- `logos/sun-symbol.svg`: símbolo solar isolado.
- `logos/app-icon-concept.svg`: proposta de ícone, requer validação para lojas.
- `tokens/colors.json`, `tokens/aurya_colors.dart`, `tokens/aurya.css`: cores para JSON, Flutter e CSS.

## Cores
Midnight Navy `#101C2C`, Ocean Blue `#1E3A5F`, Champagne `#C5B69A`, Ivory `#F4F0E8`.

## Fontes
Sugestões **não confirmadas como fontes exatas**: Cormorant Garamond para editorial, Inter para interface. Nenhum arquivo de fonte incluído. Verifique licença e adicione via fontes oficiais.

## Importante
A imagem aprovada é rasterizada. Os SVGs são **reconstruções aproximadas**, não uma extração vetorial exata do logo original. Confirme visualmente símbolo, proporções e espaçamento antes da publicação. A paleta também é uma especificação derivada da referência, sujeita à validação final. Não trate textos, imagens e telas do moodboard como assets de produção.

## Instrução curta ao Claude Code
> Use `reference/AURYA_DESIGN_REFERENCE.png` como fonte visual, os SVGs em `logos/` como ponto de partida e os tokens em `tokens/` como base. Preserve a identidade aprovada, verifique fidelidade do logo e contraste, e apresente a primeira tela implementada para aprovação antes de continuar.
